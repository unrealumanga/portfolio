How I Work

An AI-augmented practice
I don't just use AI tools — I build them.

Outside project hours I run a working lab: AI agents wired directly into the 3D software I design with. The result on live work is simple — more options explored per deadline, faster client iterations, and visualisation in hours instead of days. All tooling built in-house and run on my own hardware — Houdini/Karma, Blender, USD, MaterialX, self-hosted language and vision models.

i

AI agents inside the 3D pipeline

I've bridged AI assistants directly into Houdini and Blender, so scenes, materials and lighting can be directed conversationally while I stay focused on the design decision, not the software.

ii

Reference image to built scene

Vision pipelines that read a reference image, plan the scene, build it step-by-step and verify the result against the original.

iii

Custom models, run privately

I author and self-host my own AI models, tuned to specific tools and tasks. Client work never leaves my machines.

iv

Automated asset pipelines

SketchUp to USD to Houdini with no manual cleanup, code-generated material libraries, scripted look-dev turntables.
